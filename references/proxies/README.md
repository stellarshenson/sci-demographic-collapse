# Proxy Library

Composed **proxy blueprints** for fertility levers that lack a direct "policy → fertility" natural experiment but whose component mechanisms are researched. The principle: when the exact intervention was never run, compose a defensible estimate from the researched dynamics of its parts, and flag it honestly as a proxy, not a measurement.

## What a proxy blueprint is

Each proxy decomposes a lever into 2-4 primitive sub-mechanisms, attaches a real cited effect size to each, and composes them into one modelable term - a fertility channel, a sign, a rough ΔTFR magnitude, and the key uncertainty that makes it a proxy. Reuse: pull the composed term and its channel straight into a model; carry the citations; respect the honesty flag.

## Files

- `proxy-catalogue.md` - the blueprints (six core levers + the education interface), each ready to wire into the C/ρ/P̄/τ/S channel architecture

## Convention

Add a proxy when a lever is worth modelling but has no direct fertility experiment. Keep the component effect sizes cited (author, year) and the honesty flag current. When a direct experiment later appears, supersede the proxy with the measurement and note it.
