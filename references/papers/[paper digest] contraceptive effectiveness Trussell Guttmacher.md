## Summary

Reference typical-use and perfect-use first-year failure rates by contraceptive method.

## Key findings

- Typical-use annual failure: male condom 18%, female condom 21%, pill 9%, injectable 6%
- Long-acting/permanent: IUD 0.2-0.8%, implant 0.05%, female sterilization 0.5%, male 0.15%
- Per-act methods force a re-decision each act and leak; long-acting methods are set-and-forget

## Relevance to this project

The failure-rate gap behind H60's decision-architecture mechanism (remove long-acting methods -> effective failure rises ~2-3x). Web fact sheet - link to source.
