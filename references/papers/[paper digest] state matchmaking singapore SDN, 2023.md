## Summary

Singapore's decades-long state matchmaking effort (SDU for graduates, later SDN), the model for similar Japanese schemes.

## Key findings

- SDU produced only 2 marriages in its first year (1984-85) despite ~S$294k spent, rising to ~1,000/year within a decade
- Members' marriages rose from 2,789 (1999) to 4,050 (2003)
- Despite decades of matchmaking and incentives, Singapore's TFR kept falling - 0.97 (2024) to 0.87 (2025)

## Relevance to this project

Grounds the PARTIAL verdict on H79: state matchmaking can make some marriages but has never moved a national birth rate - a thin-market lever the deeper drivers overwhelm. Historical record - link to the program page.
